The model was never needed for calculate_stats. Mean, median, stdev, min, and max are deterministic functions of the input list, and Python's statistics module computes them exactly — there's nothing for an LLM to add. In the agent loop, the model's only real jobs were noticing from the user's message that stats were being requested and deciding which numbers to pass in, then narrating the result back in a sentence — both legitimate LLM tasks (language understanding and generation), neither of which is "doing the math." Having the model compute the mean itself would be slower, burn tokens, and — critically — isn't guaranteed correct, whereas statistics.mean() is correct by construction. The general rule: anything with a deterministic, verifiable answer — arithmetic, unit conversion, date math, sorting, exact lookups — belongs in a plain function the model calls, never in the model's own generation.
